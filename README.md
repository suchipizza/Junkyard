# 🤖 Junkyard

**The open-source parts bin for robots. Built for humans and AI agents.**

Junkyard is an open library of parametric, 3D-printable mechanical components that help AI agents, makers, and robotics developers build robots without designing every part from scratch.

### What's inside?

- 🧱 **Parametric bricks** — Customizable joints, grippers, gears, linkages, motor mounts, and more.
- 🔧 **Ready-to-generate geometry** — Adjustable parts designed for STL and STEP export.
- 🧠 **Mechanical intelligence** — Find mechanisms by function, constraints, and compatibility.
- 🤖 **Agent-native** — Designed for integration with AI coding agents through an MCP server and Python API.

### Vision

Make mechanical design knowledge accessible, reusable, and machine-readable — so building a robot becomes more about choosing the right mechanisms than reinventing them.

### Project status

🚧 **Work in progress.** Junkyard is currently in its early development stage.
