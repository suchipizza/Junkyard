# Decisions

- [`accepted.md`](accepted.md): decisions D1–D14 from the PRD (section 2), with
  where each one shows up in the repo.
- [`open.md`](open.md): open questions. O1–O3 come from the PRD; later entries
  were added during implementation. Each says which default is in use until the
  owner decides. Anything that conflicts with an invariant (PRD section 13) is
  marked `DECISION NEEDED:`.

To change a decision, edit the entry, note the date, and update the code and
tests it points to in the same PR.
